# Тайлер · Persona Lab

Кадр в роли Тайлера. ИИ-персонаж с сухим юмором, добровольными игровыми домашками и голосом в Minecraft.

Трек 1, свои интеграции: переносимая SQLite-память, управляемая запись заметок,
локальная озвучка Piper, отдельный интерфейс демонстрации и учёт API-запросов.
Игровой сеанс связывает задачу, штатный контроллер AltoClef, наблюдения мира,
ответ персонажа, историю и вывод звука. Лишних LLM-запросов при каждом кадре нет.

## Запуск

Windows, PowerShell, установленный uv. Первый раз: `./setup-kadr.ps1`.
Добавить ключ в `.env`, строка `OPENAI_API_KEY=`. Ключ не передавать в браузер.
Затем `./run-kadr.ps1`, открыть http://127.0.0.1:22228.
Для игры: в своём мире выживания нажать «Выполнить в Minecraft». Кадр сам
запускает добычу и крафт, проверяет инвентарь, затем сообщает результат.
На Windows WAV воспроизводится через системный выход, даже когда виден Minecraft.
«Остановить» отменяет задачу, останавливает движение и звук.
Для существующего локального прокси можно добавить HTTP_PROXY и HTTPS_PROXY
в `.env`; NO_PROXY должен включать localhost и 127.0.0.1.

Активная модель: GPT-6 Luna, reasoning_effort=none. Для короткого контекста
стандартные текстовые тарифы: $0.10/млн входных, $0.50/млн выходных токенов.
Источник: https://developers.openai.com/api/docs/models/gpt-6-luna
Piper работает локально, API-платежей за озвучку нет. Облачный голос не включён
по умолчанию. В проекте не запускаются фоновые бесконечные обращения к LLM.

Локальный предохранитель KADR_BUDGET_USD по умолчанию 2 доллара. Это учётная
оценка: неудачный запрос сохраняет консервативный резерв. Она может завышать
расход и не заменяет счёт провайдера. Неизвестные тарифы не считаются нулевыми.

## Память и управление

История и заметки хранятся в data/kadr.sqlite3. Сохранение заметки разрешается
галочкой для текущей реплики. Модель вызывает save_note и получает подтверждение
записи. Другому коду собеседника заметки не подставляются. «Удалить мои заметки
и историю» удаляет обе части, чтобы факт не вернулся из старого контекста.
«Остановить» блокирует следующие обращения и запись заметок; уже отправленный
запрос может быть оплачен, его ответ отбрасывается. «Продолжить» снимает остановку.

Код возвращения даёт доступ к разговору. Его нельзя показывать на публичной
записи. Эта сборка слушает только 127.0.0.1; публичный многопользовательский
сервис с авторизацией пока не развёрнут.

## Что переиспользовано

CharacterManager и формат YAML-персонажа, SQLAlchemy-модели пользователей,
диалогов и профиля из StreamerDatabase; существующая точка создания LLM-клиента.
Для OpenAI добавлен прямой ChatOpenAI-адаптер, чтобы native function calling не
зависел от необязательного MCP-адаптера LiteLLM. Остальные провайдеры сохраняют
исходный путь LiteLLM. Исходный большой интерфейс и игровой пайплайн NetTyan
сохранены, но отдельный курс-раннер не заявляет, что они уже целиком проверены.

## Minecraft

Подготовлен отдельный .minecraft-course с Minecraft 1.21.11, Fabric 0.20.1,
Fabric API 0.141.6 и UnionClef 0.95.66. Скрипты prepare_minecraft.py,
install_fabric_api.py и launch_minecraft.py фиксируют установку в data/.
Установщик переиспользует публичные assets/libraries из существующей игры.
Сохранённые аккаунты, токены и миры из пользовательской .minecraft не копируются.
Тестовый клиент запускается без токена Microsoft; это не проверка доступа
к серверам, требующим лицензионную авторизацию.

У релизного UnionClef добавлена явная зависимость на уже вложенный Tungsten:
без Fabric API загрузчик пропускал его и игра падала с NoClassDefFoundError.
Оригинальный скачанный JAR лежит отдельно. Java в песочнице не могла читать
JAR по реальному пути; рабочий запуск клиента проверяется вне этого ограничения.

Подготовка из корня проекта, после setup-kadr.ps1:

```powershell
$env:PYTHONUTF8='1'
.venv\Scripts\python.exe tools/prepare_minecraft.py
.venv\Scripts\python.exe tools/install_fabric_api.py
.venv\Scripts\python.exe tools/build_bootstrap.py
.venv\Scripts\python.exe tools/launch_minecraft.py
```

Нужен доступ к официальным загрузкам Minecraft/Fabric и релизу UnionClef.
Запуск без сохранённого аккаунта предназначен для локального тестового мира.
После создания своего мира можно входить без меню:
`python tools/launch_minecraft.py --world 'Kadr Lab'`.
Небольшой Fabric-адаптер в mods/kadr-bootstrap запускает штатную инициализацию
UnionClef, если Quick Play пропустил главное меню. Компилятор Eclipse берётся
из Maven Central с проверкой контрольной суммы; платных сервисов нет.

Реальные результаты двух игровых сценариев перечислены в EVIDENCE.md.
Это ограниченный агент для поручений, не обещание самостоятельного прохождения игры.

В тестовом мире включи ответы вручную в разделе «Общение с игроками». На mc.agicraft.ru игровой цикл запускается после входа KadrReporter. Тайлер реагирует на обращения по имени и пытается предложить задание игрокам рядом. Для проверки напиши «Тайлер, дай домашку». «Пас» закрывает приглашение.

Для Simple Voice Chat добавь мод в изолированный клиент и перезапусти его:

```powershell
.venv\Scripts\python.exe tools/setup_minecraft_voice.py
.venv\Scripts\python.exe tools/launch_minecraft.py
```

По умолчанию голос синтезирует Piper. Для голоса Тайлера отдельному Python-окружению нужны Chatterbox Multilingual 0.1.7, совместимый PyTorch и локальные веса [ResembleAI/chatterbox](https://huggingface.co/ResembleAI/chatterbox) на ревизии `5bb1f6ee58e50c3b8d408bc82a6d3740c2db6e18`. Для проверки использовали Python 3.11 и PyTorch 2.6.0+cu126. В `data/tyler-voice-config.json` задай абсолютные пути `python` к интерпретатору, `weights` к каталогу весов, `reference` к своему разрешённому WAV-образцу речи и `hf_home` к кешу Hugging Face. Поле `clips` опционально и связывает точные реплики с локальными WAV. Приложение загружает модель при старте и держит её в отдельном процессе. Результаты живого прогона в [TYLER-LIVE.md](TYLER-LIVE.md).


## Проверки и сдача

`python -X utf8 -m unittest discover -s tests -p 'test_kadr_*.py'`: проверки с настоящей
SQLite-базой и подставным ответом модели. Это не тест реальной аудитории.
`python tools/evaluate_kadr.py`, затем новым процессом `--recall`: короткие
платные проверки модели, результаты в data/course-evaluation.json.

Материалы и честный список оставшегося: STATUS.md, HOMEWORK.md, EVIDENCE.md.
Реакции случайных людей, посещаемость, баллы и решение Demo Day нельзя заменить
синтетическим тестом. Автоматического обещания зачёта нет.

Ролик: `demo/`, HyperFrames 0.9.10. Пересборка исходников и локальной озвучки:
`python -X utf8 tools/build_course_demo.py`, затем локальный HyperFrames
`check`, `snapshot --review`, `render --quality delivery -o ../docs/course/kadr-demo.mp4`.
Генератор использует публичный тестовый сценарий synthetic-evaluation.json.
Файл Arial берётся из установленной Windows при локальной сборке и не публикуется.

Настоящая игровая запись: docs/course/kadr-minecraft.mp4, метаданные
game-evidence.json. Кадры сняты публичным API игрового клиента по измеренным
временным отметкам, WAV совмещены по времени готовности. Последний кадр удержан
для конца речи. Это не запись микрофона; частота выборки кадров около 2 fps.
Редактируемая сборка: tools/render_game_recording.py и локальная data/game-recording/.
