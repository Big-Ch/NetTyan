# Ранние проверки, 7 ноября 2026

Для итоговых проверок Тайлера см. [живые прогоны 14 ноября](TYLER-LIVE.md).

Все диалоги ниже заданы оператором в тестовом сценарии. Независимых участников
пока нет. Это проверка реализации, не исследование аудитории.

## Рабочие функции

- GPT-6 Luna отвечает через OpenAI API. Ключ остаётся в локальном `.env`.
- Вызов `save_note` вернул `saved=true`; заметка записана в штатный профиль
  пользователя NetTyan через SQLite.
- Отдельный Python-процесс восстановил факт о зелёном велосипеде и тормозе.
- Другой код собеседника получил пустую память и честный ответ об отсутствии фактов.
- «Удалить» очищает заметки и диалог; «Остановить» блокирует новые запросы.
- Piper/Denis синтезирует русский WAV локально. Платного API для голоса нет.
- Проверен API запущенного Gradio-интерфейса: ответ за 4.875 с, голос создан.
  На отказ от интервью Кадр пожелал хорошего вечера, вопросов не добавил.
- Minecraft 1.21.11/Fabric/UnionClef запущен в отдельном тестовом мире.
  Настоящий tool call `inspect_minecraft` получил координаты и отсутствие других игроков.
- Полный игровой сеанс: задача оператора, inspect_minecraft, obtain_item,
  настоящая добыча и крафт AltoClef, проверка инвентаря, ответ и локальный WAV.
- В мире выживания до задания инвентарь был пуст. После: crafting_table=1,
  birch_log=1 и побочные предметы. Координаты изменились с
  [-1304.7,73,-15.5] до [-1303.7,68,-16.5]. Нативная задача заняла около 51 с.
- Второй прогон через API работающего интерфейса подтвердил wooden_pickaxe=1.
  Интерфейс вернул настоящий кадр игры; PlaySound принял воспроизведение WAV.
  Слышимость человеком отдельно не измерялась.

## Проверки

```powershell
$env:PYTHONUTF8='1'
.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_kadr_*.py'
```

Результат: 16 тестов, OK. Настоящая SQLite, подставные ответы в офлайн-тестах.
Проверены согласие на заметку, сохранение, изоляция, удаление, остановка,
лимит API, резерв при ошибке, локали координат, честный результат контроллера,
разбор игрового чата и запрет устаревшей озвучки после остановки.

Отдельно выполнены реальные платные вызовы Luna: личность, серьёзный тон,
сохранение факта, продолжение после перезапуска, другой собеседник, чтение игры,
отказ от интервью через API интерфейса. Примеры: [HOMEWORK.md](HOMEWORK.md).

## Ограничения

Первый gotoXYZ не давал проверенного движения. Переход на штатный @goto
показал изменение координат. Затем проверены настоящая добыча и крафт.
У UnionClef найден дефект Quick Play: основная инициализация привязана к главному
меню. Адаптер KadrBootstrap исправил быстрый вход, шлюз запустился и оба задания прошли.

Игровой чат с независимым человеком и доставка голоса в сетевой голосовой чат
не проверены. Полного автономного прохождения и строительства произвольных
сооружений не заявляем. Сеанс ждёт задачу оператора; контроллер добычи и крафта
переиспользует готовый AltoClef. Длинные задачи ограничены 120 секундами.

Полные приватные журналы лежат в `data/` и исключены из Git. Публичная сводка
содержит только придуманный тестовый сюжет про велосипед.

Учёт API включает резервы неудачных запросов и не заменяет кабинет провайдера.
Текущая модель только Luna; обычные ответы в проверках занимали
около 2–6 с, один запрос занял 54 с, один завершился тайм-аутом.
